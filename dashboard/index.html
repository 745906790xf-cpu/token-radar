How the implied value is built

The market already prices tokens per dollar of TVL: for every protocol whose token trades, mcap / TVL is a realised multiple. Protocols in one category trade at similar multiples, so each category is priced at the median mcap/TVL of its trading members (three or more needed; thinner categories use the whole market's median, shown as “fallback”). Multiples are clamped to 0.02–2.50 so one outlier cannot price a whole board.

implied = TVL × category multiple × growth × maturity × chains

  • Growth — 1 + (7-day TVL change, clamped to −50%…+100%) × 0.4.
  • Maturity — 0.70 + (days since first listed, capped at 4 years) ÷ 4 years × 0.30. A protocol with no listing date is scored at 365 days.
  • Chains — 1 + 0.02 per chain beyond the first, at most 1.08.

No protocol name is ever special-cased: one function scores every row, and each detail view prints the full arithmetic so a reader can check it. The board ranks pre-token protocols only; protocols whose token already trades are listed separately at their market caps.

Honesty line. The snapshot records whether a protocol has a token on file — a protocol is said to record no token, never that it has none. The implied value is this entry's own claim, never make.fun's, and it predicts nothing about whether or when a token is issued.
